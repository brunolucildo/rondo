# Screenshots — spec 0018 (redesign retro 8-bit)

Comparação visual antes e depois do redesign de `.specs/0018-ui-redesign-retro-8bit.md`.

## Como foram capturados

- **Commit-base dos `_before`:** `d2a2484` (`feat(api)!: escolhe o provedor de e-mail por NODE_ENV e remove EMAIL_PROVIDER`), com nenhuma alteração de UI na árvore de trabalho (só `.mcp.json` e a spec).
- **Ferramenta:** `scripts/capture-screenshots.mjs` (Playwright, Chromium), a partir da dependência `@playwright/test` que o repositório já tem. O Playwright MCP está registrado em `.mcp.json`, mas não conectou na sessão da implementação (`CONNECTION_CLOSED`); por decisão do usuário a captura usou o Playwright pelo terminal.
- **Reprodução:** suba `apps/app` (5173) e `apps/docs` (3001) com `bun run dev --filter=app` e `--filter=docs`, depois rode `node scripts/capture-screenshots.mjs --phase before|after` (`--only a,b` limita as telas).
- **Dados e estados (Q2):** toda chamada à API é interceptada no navegador com dados fictícios (pessoa "Alex Morgan", `alex@example.test`, token e senha inventados). Não há API, banco nem `DATABASE_URL`; nenhum dado, e-mail ou token reais aparecem.
- **Viewport:** 1280×800 (desktop), 375×812 (`-mobile`), `deviceScaleFactor` 1, tema claro (os `-dark_after` usam `prefers-color-scheme: dark`, 1280×800). Captura só da janela (sem rolagem), para que o par tenha a mesma dimensão; estados longos ficam cortados na borda inferior nos dois lados.
- **Animações** desligadas na captura (`animations: "disabled"`); o indicador de dev do Next.js é ocultado em `docs-home`.
- **Nomes:** `<pagina>_before.png`, `<pagina>_after.png`; variantes `<pagina>-mobile_*` e `<pagina>-dark_after`.

## Observação sobre o catálogo

`sign-in-errors` mostra o erro de campo (envio vazio). O erro geral de credenciais limpa os erros de campo no código, então ele aparece em um quadro próprio: `sign-in-error-general` (além do catálogo da spec).
